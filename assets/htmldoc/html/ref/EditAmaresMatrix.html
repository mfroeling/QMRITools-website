EditAmaresMatrix

EditAmaresMatrix[matrix]

is used to edit the Amares fitting matrix which can be compressed or extended using ToFullAmaresMatrix or FromFullAmaresMatrix. The default properties are "amp": -1,"sigma": 0,"gamma": -1,"shift": -1,"phase": 0,"B1": False,"init": False.

EditAmaresMatrix[matrix,names]

will do the same but will only do it for the values in the list names. If values are not in matrix they will be added, if values are names but not in matrix they will be removed from matrix.
