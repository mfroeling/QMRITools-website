ShowTrainLog

ShowTrainLog[folder]

shows an interactive plot of the training log stored in folder as JSON files.

ShowTrainLog[folder,min]

filters rounds with fewer than min progress entries. Default is 5. The interface allows selecting metrics, toggling log scale, Gaussian filtering, and live folder reloading.
