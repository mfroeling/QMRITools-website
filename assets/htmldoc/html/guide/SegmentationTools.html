SegmentationTools

QMRITools package: functions for segmenting muscle data using convolutional neural networks.

SegmentData — Segments out of phase Dixon muscle data.

ClassifyData — Classifies an image using a pretrained classification network.

TrainSegmentationNetwork — Train a network that can be used in SegmentData.

RunMuscleMap — Runs MuscleMap segmentation on a nii file or data.
