MuscleBidsTools

QMRITools package: Functions related to file management according to the Muscle-BIDS standard.

PartitionBidsName — Converts a Bids name to the a Bids label as an association.

GenerateBidsName — Generates a Bids file name from the Bids labels association.

$debugBids — a debug flag for Bids functionality.
