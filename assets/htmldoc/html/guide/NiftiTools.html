NiftiTools

QMRITools package. Functions for importing and exporting Nifti (*.nii) data.

DcmToNii — Converts DICOM files to nifti (*.nii) using Cris Rodens Dcm2Nii.exe.

ImportNii — Import data from Nifti (*.nii).

ExportNii — Export data to Nifti (*.nii).
