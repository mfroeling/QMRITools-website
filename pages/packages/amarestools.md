This toolbox provides AMARES fitting of MR spectroscopy data. It includes construction of the basis (`AmaresBasis`), automatic starting values (`AmaresInitialValues`), the fit of an FID (`AmaresFitFidI`) with analytic Jacobians, and a parameter matrix that can be edited to constrain the fit (`EditAmaresMatrix`, `ShowParameterMatrix`).
